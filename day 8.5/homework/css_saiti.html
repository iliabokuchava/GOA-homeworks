CSS

CSS (Cascading Style Sheets) არის სტილის ენა, რომელიც გამოიყენება HTML დოკუმენტის ვიზუალური იერსახის,
განლაგებისა და დიზაინის აღსაწერად. თუ HTML ვებსაიტის „ჩონჩხია“, CSS არის მისი „კანი და ტანსაცმელი“, რომელიც განსაზღვრავს ფერებს, შრიფტებს,
ზომებსა და ანიმაციებს.

ძირითადი ფუნქციები:

  1. ვიზუალური გაფორმება: ფერების, ფონის, ტექსტის ფორმატისა და შრიფტების მართვა.
  2. განლაგების კონტროლი: ელემენტების პოზიციონირება, ბადეების (Grid) და ელასტიური ბლოკების (Flexbox) შექმნა.
  3. ადაპტურობა (Responsive Design): საიტის მორგება ტელეფონების, პლანშეტებისა და კომპიუტერების ეკრანებზე.
  4. კოდის ოპტიმიზაცია: ერთი ფაილით მთელი ვებსაიტის ასობით გვერდის სტილის ერთდროულად შეცვლა.

CSS-ის ჩართვის 3 მეთოდი:

    • Inline (შიდა კოდში): სტილი იწერება პირდაპირ HTML ტეგის style ატრიბუტში.
    • Internal (შიდა სტილი): იწერება HTML ფაილის head სექციაში, style ტეგებს შორის.
    • External (გარე ფაილი): სტილები იწერება ცალკე .css ფაილში და HTML-ს უკავშირდება ტეგით.
