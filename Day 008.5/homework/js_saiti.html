JavaScript

JavaScript (JS) არის მაღალი დონის, ინტერპრეტირებადი პროგრამირების ენა,
რომელიც ვებგვერდებს ხდის დინამიურს და ინტერაქტიულს. ის HTML-თან და CSS-თან
ერთად წარმოადგენს მსოფლიო აბლაბუდის (World Wide Web) სამ ძირითად საყრდენ ტექნოლოგიას.

რისთვის გამოიყენება JavaScript?

  • Front-End დეველოპმენტი: აცოცხლებს ვებგვერდის ინტერფეისს (ანიმაციები, ფორმების ვალიდაცია, მენიუები).
  • Back-End დეველოპმენტი: Node.js-ის დახმარებით შესაძლებელია სერვერული პროგრამების და ბაზების მართვა.
  • მობილური აპლიკაციები: React Native-ის ან Ionic-ის საშუალებით იქმნება აპლიკაციები iOS და Android სისტემებისთვის.
  • თამაშების დეველოპმენტი: ბრაუზერზე დაფუძნებული 2D და 3D თამაშების შექმნა.

ძირითადი მახასიათებლები:

  1. ინტერპრეტირებადია: ბრაუზერი პირდაპირ კითხულობს და ასრულებს კოდს კომპილაციის გარეშე.
  2. მულტიპლატფორმული: მუშაობს ნებისმიერ თანამედროვე ბრაუზერში და ოპერაციულ სისტემაში.
  3. ობიექტზე ორიენტირებული: მხარს უჭერს ობიექტებთან მუშაობის ფუნქციონალს.
  4. დინამიური ტიპიზაცია: ცვლადის შექმნისას მონაცემთა ტიპის (ტექსტი, რიცხვი) წინასწარ მითითება საჭირო არ არის.

პოპულარული ფრეიმვორკები და ბიბლიოთეკები

    • React: UI კომპონენტების ასაგებად შექმნილი ბიბლიოთეკა Meta-სგან.
    • Angular: სრულყოფილი ფრეიმვორკი კომპლექსური ვებ-აპლიკაციებისთვის Google-სგან.
    • Vue.js: პროგრესული და მარტივად ასათვისებელი ფრეიმვორკი ინტერფეისებისთვის.
