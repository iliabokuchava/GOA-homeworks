inline CSS - იწერება ელემენტის გამხსნელ თეგში და იმყოფება HTML ფაილში
internal CSS - იმყოფება HTML ფაილში, მაგრამ იწერება ცალკე <style></style> თეგში
external CSS - არის ცალკე CSS ფაილი რომელიც უკავშირდება HTML ფაილს link - ის დახმარებით

პრიორიტეტული გასტილვის მეთოდებია:
1. inline CSS
2. id
3. class
4. element
